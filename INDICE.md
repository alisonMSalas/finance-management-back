## 🚀 Comandos Rápidos

### Ver Documentación
```bash
# Abrir en navegador predeterminado (Windows)
start build\docs\javadoc\index.html

# Abrir en navegador predeterminado (Linux/Mac)
open build/docs/javadoc/index.html
```

### Generar Documentación
```bash
# Windows
.\gradlew.bat javadoc

# Linux/Mac
./gradlew javadoc
```

### Limpiar y Regenerar
```bash
# Windows
.\gradlew.bat clean javadoc

# Linux/Mac
./gradlew clean javadoc
```
